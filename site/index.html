它在做什么

Sense 从你看过、听过、截过、和 AI 聊过的东西里整理出一张张卡，放进口袋。你留下、丢掉、抽卡回答，它就越来越清楚你在意什么，再替你去找新的。不打分、不算百分比，每张卡都能追到证据。

石

刚进来，还没处理。7 天没理会就碎掉，只留下"查到过"。

铜

你留下了，说明有点在意。

银

在关注：它自己有新一话、新作、新论文时告诉你。

金

一种口味：两张银卡说得出同一个为什么就融合成金，按口味往外推荐。

桌上的伙伴

口袋会站在你的桌面上。谁站在那儿由你自己选，它只演口袋里真发生的事，不演假的。

口袋精小可爱 · 口袋本身

个子最小，抱着石、铜、银、金四张卡。进卡会吃，碎卡会抖，有事会举手。

Claude大小姐 · 引擎用 Claude 时

自称「本小姐」，骄傲但从不马虎：查到什么都记进账本，查不到就直说。

DeepSeek大肥鱼 · 引擎用 DeepSeek 时

圆滚滚、慢吞吞，什么都拿吃的打比方。联网搜索它自己在服务端跑。

角色桌宠从下一版开始（现在的 0.1.0 是像素口袋）。每个角色之后还会有男版，也由你手动选。

点一下桌宠弹快捷菜单，双击打开口袋，把图片拖到它身上就是喂进口袋。气泡说到哪张卡，点气泡就跳过去。

引擎可选 Claude / DeepSeek

同一套只读工具和规矩，换一个模型跑。用 DeepSeek 时把自己的 key 写进本机配置，联网搜索由 DeepSeek 执行。

和桌上那位打电话实验中

中文、日语、英语。问它口袋里有什么、哪张快碎了，用嘴回答「要问你的」是非题，它复述一遍你说「对」才记。录音和逐字稿都不留。

截图键 ⌃⇧⌘A，可以改

截完同时放进剪贴板，⌘V 就能贴。也可以打开「收剪贴板里的截图」，别的工具截的图会问一句要不要。

每张卡都有谱系

点开一张卡，能看到它从哪来、推出了什么：哪张金卡推荐的、哪次追踪查到的，一路点过去。

数据从哪来

  • ⌃⇧⌘A 截一块屏幕（或收剪贴板里别的工具截的图）、开着的剪贴板记录、把图片拖给桌宠。
  • 你自己的 Chrome 履历和 YouTube 观看记录，在本机读，读完即删副本。
  • 你登录着的 YouTube Music / Spotify 页面：Claude 只读白名单里的几页，只记歌名和歌手。
  • 你和 Claude Code 的会话日志里，你说过的判断。

所有东西存在你的 Mac 上，不上传。agent 调用都是本机的 Claude Code，用你自己的账号。

安装前要知道

  • 只支持 macOS（Apple 芯片），需要已安装并登录的 Claude Code。读听歌页面还要装 Claude in Chrome 扩展。
  • 安装包没有经过 Apple 公证。第一次打开被拦时，到「系统设置 › 隐私与安全性」点「仍要打开」。
  • 用 DeepSeek 当引擎是可选的：在 ~/Library/Application Support/Sense/config.json 里填自己的 deepseek_api_key。key 只留在你的 Mac 上。
  • 语音通话还在实验：需要在本机另外跑一个语音服务，第一次打电话时会问麦克风权限。
  • 要读 Chrome 履历，请在「完全磁盘访问权限」里打开「Sense 口袋」；不打开也能用，只是少一个来源。
