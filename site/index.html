它在做什么

Sense 从你看过、听过、截过、和 AI 聊过的东西里整理出一张张卡，放进口袋。你留下、丢掉、抽卡回答，它就越来越清楚你在意什么，再替你去找新的。不打分、不算百分比，每张卡都能追到证据。

石

刚进来，还没处理。7 天没理会就碎掉，只留下"查到过"。

铜

你留下了，说明有点在意。

银

在关注：它自己有新一话、新作、新论文时告诉你。

金

一种口味：两张银卡说得出同一个为什么就融合成金，按口味往外推荐。

数据从哪来

  • ⌃⇧⌘A 截一块屏幕（或收剪贴板里别的工具截的图）、开着的剪贴板记录、把图片拖给桌宠。
  • 你自己的 Chrome 履历和 YouTube 观看记录，在本机读，读完即删副本。
  • 你登录着的 YouTube Music / Spotify 页面：Claude 只读白名单里的几页，只记歌名和歌手。
  • 你和 Claude Code 的会话日志里，你说过的判断。

所有东西存在你的 Mac 上，不上传。agent 调用都是本机的 Claude Code，用你自己的账号。

安装前要知道

  • 只支持 macOS（Apple 芯片），需要已安装并登录的 Claude Code。读听歌页面还要装 Claude in Chrome 扩展。
  • 安装包没有经过 Apple 公证。第一次打开被拦时，到「系统设置 › 隐私与安全性」点「仍要打开」。
  • 要读 Chrome 履历，请在「完全磁盘访问权限」里打开「Sense 口袋」；不打开也能用，只是少一个来源。
