# 卡片系统 v1.2 草案（第二稿）：七种卡、属性、铜卡与金卡

状态：**已并入 SENSE.md v1.2（2026-10-21，作者："可以可以"）**。本文件保留为讨论记录，权威定义以 SENSE.md 7.5、7.1、7.8 为准。第 4 节的"灰 / 铜 / 金"已被第 9.2 节的"石 / 铜 / 银 / 金"取代。

## 1. 一句话模型：三个轴

作者 2026-10-21 的话："这两个是行为（动作）、是什么（卡的 category）和状态（卡的颜色）"。即一张卡同时有三个互不替代的轴：

| 轴 | 取值 | 谁定 |
|---|---|---|
| **类别**（卡是什么） | 判断 / 推荐 / 人物 / 关注 / 兴趣 / 金句 / 收藏（截图与书签） | 来源和内容决定，第 2 节 |
| **动作**（你对它做什么） | 每种类别一套，见第 2 节最后一列。归成两类：判断卡问"对不对"，其余六种问"留不留 / 跟不跟" | 类别决定动作集 |
| **颜色**（状态） | 灰 = 刚进来、还没被你留下 → 铜 = 你留下了 → 金 = 属性被多次使用，且这张卡自己也被用过 | Sense 按第 4 节的规则升降 |

第一稿把"动作"当成了分类依据，错在把两个轴压成一个。本稿以类别为卡的身份，动作跟着类别走，颜色跟着使用走。

- **卡**是你生活里的一个东西：一次决定、一个人、一部在追的作品、一句话、一个随手存的东西、一个网页、一次被你喜欢过的推荐。
- **属性**是卡背后的 sense：这张卡为什么在你这里。同一个属性会出现在很多卡上。
- 属性被用得多，卡就从**铜卡**升成**金卡**。金卡不消失。铜卡长期没用会退场。

卡是你看得见的；属性是 Sense 维护的。SENSE.md 里的"判断"（场 / 选择 / 对照 / 理由）在这个模型里是**属性**的内容，不再是一种卡。

## 2. 七种卡

| 卡 | 是什么 | 从哪来 | 卡面 | 你能做什么 |
|---|---|---|---|---|
| **判断卡** | 你在什么时候、做什么事、下了什么决定 | 会话日志里你的原话；你截图或复制的自己的话；你在卡上答的一句 | 日期 ＋ 场合 ＋ 决定了什么（放弃了什么）＋ 一句为什么 | 对 / 不对 / 改一句 |
| **推荐卡** | Sense 之前推荐过、你点过喜欢的东西。新推荐先是灰卡，你 like 或 almost 后才变铜 | Sense 的推荐 ＋ 你的 like / almost | 条目 ＋ 当时为什么推 ＋ 你当时的反应 | 再看 / 升为收藏或关注 / 其实不喜欢 |
| **人物卡** | 你联系过、高评价过、关注了、cold email 过的人 | 邮件（收发双方、主题、日期；你自己写的正文）；会话里提到的人；浏览器里反复去的个人主页；社媒关注、日历、聊天平台的联系人（v1.1） | 名字 ＋ 关系（联系过 / 关注 / 想联系）＋ 你为什么在意 ＋ 最近动向 | 跟 / 不跟 / 记一次联系 |
| **关注卡** | 长期订阅、追踪的内容：作品、系列、频道、idol | 浏览器履历里跨周反复出现的同一条目；你说"我在追" | 条目 ＋ 你追到哪 ＋ 有什么新的 | catch up / 看了 / 不追了 |
| **兴趣卡** | 和你个人兴趣有关的东西：爱好、喜欢的题材、在意的方向（"跑团""降维物理模拟""川井憲次的配乐"） | 浏览器履历；会话；截图；平台数据 | 兴趣 ＋ 相关的卡 ＋ 最近新的 | 是 / 不是我在意的 |
| **金句卡** | 一句话：你说过的、别人说你留下的 | 剪藏；会话里你自己的句子；浏览器里的引文页 | 那句话 ＋ 谁说的 ＋ 什么时候留下的 | 留 / 删 |
| **收藏卡** | 随手存的东西。两个来源合成一种卡，卡面角标区分：**截图**（你框下来的一块屏幕）和**书签**（浏览器 bookmark、会回去的网页） | 自带截图；浏览器书签；剪贴板；GitHub star | 截图：缩略图 ＋ OCR 文字 ＋ 来源。书签：标题 ＋ URL ＋ 存的时候在干什么 | 留 / 删 / 升为关注 / 打开 |

书签和截图合并为收藏卡（作者 2026-10-21："可能可以合并"）。

七种卡的卡面不同，像素图的边框和颜色不同，一眼能认出种类。金卡换金边。

## 3. 属性

属性是 sense 本身，是一句你会说出口的话，带为什么：

- 「实装到底，发布要等我看过」——因为发布不可撤回
- 「世界不能顺着玩家」——有谜底，信任度完全不一样
- 「角色要离开我之后还在、还会变」
- 「文字要像一个具体的人写的」——不要把道理直接说出来

规则：

| 项 | 规则 |
|---|---|
| 形态 | 一句话 ＋ 一句为什么。可选：它反对的是什么（对照）。这就是 SENSE.md 的四要素，只是不再做成一种卡 |
| 从哪来 | Sense 从判断卡里提炼（一次决定 → 一条属性）；从金句卡里提炼；从你对任何卡的"为什么"里提炼 |
| 挂在哪 | 每张卡 1–3 条属性。关注卡"来自深渊"可以挂「要有谜底的世界」；人物卡可以挂「做能在交互里跑起来的物理」 |
| 什么算"用了一次" | 举例：属性「要有谜底的世界」。你留下一张《来自深渊》的关注卡，它挂着这条属性，算一次；你 catch up 了它的新一话，算一次；你截了一张推理游戏的图，Sense 给它挂上这条，你留下了，算一次。**一句话：你每次留下、打开、跟进一张挂着这条属性的卡，就算这条属性被用了一次** |
| 状态 | 候选（Sense 提的）→ 已确认（你在某张卡上点过"对"或改过它）。只有已确认的属性能让卡升金 |
| 显示 | 卡背面列出属性；点属性能看到挂着它的所有卡。这就是"你的 sense"的页面：不是一张签名卡，而是一张属性清单，每条后面跟着它串起来的卡 |

## 4. 铜卡与金卡

| | 灰卡 | 铜卡 | 金卡 |
|---|---|---|---|
| 怎么来 | 任何入口进来的东西（截图、复制、履历扫描、Sense 的新推荐） | 你在灰卡上点"留"，或对它做了任何正向动作 | 卡上的**已确认**属性被用得够多，且**这张卡自己**也被用过（打开、catch up、检索命中后点开）。刚挂上热门属性的新卡不会直接变金。"够多"不写死，见下方 |
| 会不会消失 | 7 天没处理：自动归档。截图例外，留 30 天 | 60 天没被看、没被用、没被 catch up：归档（不删，不再出现在口袋里，检索还能搜到） | 不会自动消失。关注卡的金卡持续 catch up；判断卡的金卡进档案；人物卡的金卡持续看动向 |
| 降级 | — | — | 你在金卡上点"不对 / 不追了 / 其实不喜欢"：卡归档，属性的用次减一；属性被你改掉：挂着它的金卡回到铜卡重新算 |

**门槛是调出来的，不是设出来的**（作者 2026-10-21）。起始值只为让第一叠卡能跑：属性被用 3 次。之后按你的行为调：你手动把一张铜卡标成"这个要留着"，说明门槛太高；金卡被你降级或从不打开，说明门槛太低。每次整理时 Sense 按这两个信号挪一次门槛，并写一句"门槛从 3 调到 4，因为……"。不同类别可以有不同门槛。

"属性被多次使用"是升金的唯一条件。所以一个东西能不能留下来，取决于它和你其他的选择连不连得上，而不是它本身多好。这和 SENSE.md 1.4 的"独特 = 你的选择和默认的分岔"是同一件事：孤立的喜欢是铜，串成线的喜欢是金。

## 5. 入口与来源分工

作者列的入口：浏览器 history log；Codex 与 Claude 会话（包括 agent 替你做的搜索）；截屏与截图（**Sense 自带**，不是 v2）；剪贴板；平台数据；Sense 自己的 UI 操作。另加 Sense 主动的 web search。全部进口袋，进来时是灰卡，你留下后成铜卡。

| 入口 | 出哪种卡 | 读法 |
|---|---|---|
| 会话日志（只取用户轮次） | 判断卡、金句卡（你自己的句子）、人物卡（你提到要联系的人） | 现有 7.1 规则；M0 v2 已验证 |
| 会话里 agent 替你做的搜索（WebSearch / WebFetch 的查询词） | 兴趣卡候选、收藏卡候选 | 只取 tool_use 输入里的查询词，不读工具输出（防注入）；和你随后在对话里认可的结果配对；权重低于你自己写的话。需要改 SENSE.md 7.1 的"不读 assistant 输出"，开这一个口子 |
| 浏览器履历与书签 | 关注卡、人物卡（反复去的主页）、收藏卡（书签）、兴趣卡 | **全部扫**（作者 2026-10-21），不按站点筛，替代 SENSE.md 7.1 的路径包含规则。只排除两类：别人的 profile；登录、支付、银行、医疗、签证、后台类页面。出卡用频次：同一条目跨 ≥3 周、≥5 次才成灰卡；单次访问只进检索 |
| 截屏与截图（Sense 自带：全局快捷键截屏、框选文字或图片、分享菜单） | 金句卡、收藏卡；偶尔判断卡（你截了一段自己的话） | 截图先 OCR 与识别（一页漫画、一条推、一段论文），猜它挂哪张卡或哪条属性，原图删，只留文字、缩略图与来源 |
| 平台数据（邮件、GitHub star、Steam、Bilibili / YouTube 订阅、社媒关注、日历） | 人物卡、收藏卡、关注卡 | 连接器只给"你消费 / 关注 / 联系了什么"，不给理由。邮件读收发双方、主题、日期，以及你自己写的正文；别人写的正文不存、不引用。v1 先邮件和 GitHub，其余 v1.1 |
| 剪贴板（复制的那一刻 ＋ 粘贴到了哪里） | 灰卡：金句、收藏；粘到 agent 里的那段是判断卡的上下文 | 见 5b。来源 app 与目的 app 成对记录；粘进 Claude Code / Codex 的内容与会话日志去重，只记一次 |
| Sense 的 UI 操作（对 / 不对 / 跟 / 不跟 / catch up / 留 / 删、升为关注、点开属性） | 不出新卡；改属性的状态与用次、改卡的颜色 | 这就是 F 环的纠正来源；每个动作都带时间，算"使用" |
| web search（Sense 主动） | 关注卡和人物卡的"最近动向"，推荐卡 | 只送出条目名和人名（公众人物） |

"看 log 不看 tab"在这里落实为：判断卡只从你自己写的话来（会话日志为主，截图或复制的自己的话为辅）；浏览器履历永远不出判断卡，只出关注、收藏、人物、兴趣，这些不需要理由就能成立。

**app 的分量**：作者 2026-10-21："卡和收藏的 app 可以做得好一点"。三个轴的呈现可以好看，但卡与收藏的 app 本身要做好：口袋、截屏、剪贴板、整理、七种卡面、金卡，这些是产品主体，不是 CLI 的附属。5.1 的"两个面"要改为：**app（卡与收藏）为主面，CLI 为引擎与调试面**。原生 app 不再放 v2；v1 先做 macOS（截屏与快捷键最顺手），iOS 靠分享菜单把东西送进口袋。

## 5a. app：口袋

作者 2026-10-21："做成口袋，和比较好检索的一个 UI，自带一个截图的工具，截图完了之后自动作为一个生成卡的动作。"

**口袋**是 app 的唯一主界面：所有卡都在口袋里，没有"收件箱"和"收藏夹"两个地方。灰卡在口袋最上面等整理，铜卡按时间往下排，金卡固定在口袋底部的一层不会被冲走。

| 部分 | 做什么 |
|---|---|
| 口袋 | 一列卡，最新在上。顶部是今天进来的灰卡（截图、剪藏、履历扫出来的），一次一张滑掉或留下。往下是铜卡。拉到底是金卡层 |
| 检索 | 一个搜索框 ＋ 三个轴的筛选：类别（七个图标）、颜色（灰 / 铜 / 金）、属性（点一条属性看它串的所有卡）。全文搜卡面、OCR 文字、来源标题；时间轴按周折叠。检索结果也是卡，不是列表 |
| 截图 | 全局快捷键 → 框选屏幕任意区域 → 松手即生成一张灰卡，出现在口袋顶部，带缩略图、OCR 文字、来源 app 与窗口标题。没有表单。你可以不管它，整理时再处理 |
| 自动生成 | 截图落下后 Sense 在本机做三件事：认出它是什么（一页漫画、一条推、一段论文、一个商品、一个人的主页）→ 猜类别（金句 / 收藏 / 人物 / 关注 …）→ 猜挂哪条属性或哪张已有的卡（追的那部作品的新一话就挂到那张关注卡上，不另开卡）。猜错了，你在卡上改类别或拖到另一张卡上 |
| 一键 | 灰卡只有两个动作：留（变铜）/ 丢。类别和属性是 Sense 填好的，你只纠正 |

截图即建卡，这一条决定了入口的优先级：macOS 全局快捷键截图是 v1 第一个要做的入口，先于浏览器履历扫描和平台连接器。因为它是唯一一个"你想留的那一刻"就能用的入口，其他入口都是事后补的。

隐私：截图原图在识别后删除，只留缩略图（低分辨率）、OCR 文字、来源。识别在本机或经你指定的 API，截图不上传到 Sense 以外的任何地方。含密码框、支付页、聊天窗口的截图，Sense 识别到就提示"这张不建议留"，默认丢。

## 5b. 剪贴板：复制即留痕

作者 2026-10-21："复制剪贴板里面的东西，其实都是我们的 context，可以记录下来。比如复制到了 Agent 里面，或者放到什么地方都可以记录下来。"

复制比截图更频繁，而且多一样截图没有的东西：**去向**。从哪复制、粘到哪，本身就是一次选择。从论文里复制一段粘进 Claude Code，说明这段被你拿去用了；从推特复制一句粘进备忘录，说明你想留。

| 记什么 | 怎么拿到 | 备注 |
|---|---|---|
| 内容 | macOS `NSPasteboard` 的 changeCount 轮询（约 0.5 秒），取文本、图片、文件路径、URL | 不需要特殊权限 |
| 来源 | 复制那一刻的前台 app 与窗口标题；浏览器里是页面标题 | 前台 app 不需要权限；窗口标题需要"辅助功能"或"屏幕录制"权限 |
| 去向 | 监听 ⌘V 时的前台 app 与窗口标题，和最近一次复制配对 | macOS 不直接告诉你粘到了哪；要靠全局按键监听，需要"辅助功能"权限。右键菜单粘贴、拖放抓不到，只能部分记录 |
| 时间 | 复制与粘贴各一个时间戳 | 复制后 10 分钟内没有粘贴 = "只复制没用"，权重最低 |

**卡怎么生成**：不是每次复制都成卡，否则口袋会被淹。规则：

- 复制后粘贴到 agent（Claude Code、Codex、Cursor、ChatGPT 网页）：记为该会话的上下文，挂到之后从这段会话里抽出的判断卡上，作为"你当时拿给 agent 看的东西"。不单独成卡。
- 复制后粘贴到笔记、备忘录、文档、聊天：成一张灰卡，类别由 Sense 猜（金句 / 收藏）。
- 同一段文字或 URL 一周内复制 ≥2 次：成一张灰卡，不管粘到哪。
- 其余只进本地流水（保留 14 天，用于去重和检索），不出现在口袋里。

**不记什么**（读取边界，硬规则）：

- 密码管理器与系统标记为私密的内容：pasteboard 类型含 `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType` 的一律跳过（1Password、Bitwarden、钥匙串都打这个标）。
- 来源或去向是终端里的 ssh / sudo 提示、密码框、支付页、银行 app 的：跳过。
- 内容匹配密钥样式、邮箱、电话、卡号、≥32 位 hex/base64 的：跳过整条，不是脱敏后保留。
- 来源是聊天、邮件 app 的内容（多半是别人写的话）：跳过。要留别人的一句话，用截图，并且它只能成金句卡，不能成判断卡。
- 用户可以设黑名单 app，以及一个"暂停 1 小时"的开关。
- 本地流水是原始记录，按 SENSE.md 第 9 节同等对待：加密存在本机，不进 KB，不进任何导出，14 天滚动删除。

**和截图的关系**：截图是"我主动要留"，复制是"我顺手用了"。截图每次都成灰卡；复制按上面的规则筛。两者进同一个口袋、同一套类别和属性。

## 6. 重复发生的事（G 环）

| 子环 | 触发 | 做什么 |
|---|---|---|
| 跟踪 | 关注卡、人物卡的金卡，默认每周一次 web search | 按挂着的属性过滤动静，出一张"更新"（挂在原卡上，不是新卡）。你说"我忘了"时，从上次 catch up 的点补到现在 |
| 整理 | 每周，或你按一下 | 过期灰卡归档；给新铜卡补类别与属性；Sense 提属性候选；算升金 / 归档；把三个月内同一个方向的铜卡合成一张兴趣卡候选 |
| 推荐 | 你问，或整理时顺带 | 用已确认属性去外面找；你 like 的变成推荐卡留着 |

## 9. 玩法：参照《小丑牌》（Balatro）与《苏丹的游戏》

作者 2026-10-21："按照 Joker 卡牌游戏或者苏丹的游戏一样，去设置卡片的感觉和游玩机制；卡片可以融合；卡片可以放进卡槽，agent 可以有 4–5 个卡槽。"

### 9.1 从两款游戏借什么

| 游戏 | 机制 | 在 Sense 里变成 |
|---|---|---|
| 小丑牌 | 5 个小丑槽，小丑是被动修正，从左到右结算；加法在前、乘法在后，顺序改变结果；有的小丑看邻居（Blueprint 复制右边那张） | agent 的 4–5 个卡槽；槽里的卡决定 agent 这一次怎么找、怎么挑；顺序有意义；部分卡有邻接效果 |
| 小丑牌 | 每次出牌，分数从每张小丑上一跳一跳地冒出来 | 每条结果上标出它来自哪张槽卡的哪条属性："＋「要有谜底」→《来自深渊》新一话" |
| 苏丹的游戏 | 事件有格子，把人物、物品放进去按属性判定；卡分品级（铜、银、金），品级越高越强也越难拿；苏丹卡七天限时 | 委托：带格子的任务，放对的卡才能开；卡分四个品级；委托有期限 |
| 苏丹的游戏 | 卡会在事件里被消耗、转化成新卡 | 融合：几张卡合成一张更高品级的卡；原卡不删，叠在新卡下面当证据 |

### 9.2 品级：石、铜、银、金

替代第 4 节的"灰、铜、金"，向苏丹的游戏靠拢：

| 品级 | 是什么 | 怎么到这一级 |
|---|---|---|
| 石 | 刚进来，还没被你留下（原"灰卡"） | 任何入口 |
| 铜 | 你留下了 | 点"留"或任何正向动作 |
| 银 | 融合出来的卡，或带一条已确认属性的卡 | 融合；或你在卡上确认了属性 |
| 金 | 属性被用得够多，卡自己也被用过；不会自动消失 | 第 4 节的规则，门槛靠调 |

槽里只能放铜以上。石卡要先留下。

### 9.3 agent 卡槽

每个 agent 有一排卡槽，起始 4 个，第一张金卡出现时解锁第 5 个。agent 可以有多个，每个是一套存起来的配置，例如"追番""读论文""找人聊"。

| 槽位 | 作用 | 小丑牌里的对应 |
|---|---|---|
| 左边的槽 | **约束**：先筛。放判断卡、兴趣卡，决定"只看什么、不看什么" | 加法小丑，放前面 |
| 中间的槽 | **对象**：从哪里找。放人物卡、关注卡、收藏卡，决定起点 | 出牌本身 |
| 右边的槽 | **口味**：最后排序。放金句卡、判断卡，决定"挑哪个、怎么说为什么" | 乘法小丑，放后面 |
| 第 5 槽（解锁后） | **野卡**：Sense 自己放一张你档案外的卡，专门往盲区找一条 | 小丑本身 |

同一张卡放左边和放右边效果不同：判断卡「世界不能顺着玩家」放左边，没有对抗机制的作品直接被筛掉；放右边，它们还在，只是排到后面。

**邻接效果**（第一批，之后随玩随加）：

| 组合 | 效果 |
|---|---|
| 人物卡 ＋ 右边紧挨着兴趣卡 | 找这个人在这个兴趣里的新东西，而不是他所有的动向 |
| 人物卡 ＋ 判断卡 | 起草一封 cold mail，理由用这条判断（superconnector 的最后一跳） |
| 金句卡 ＋ 任意卡 | 结果卡上的"为什么"用这句话的口吻写 |
| 关注卡 ＋ 关注卡 | 只找两部作品都沾边的东西（同一作者、同一类型、同一批粉丝在聊的） |

**出一手**：你给 agent 一句话（"周末想看点什么"），agent 带着槽里的卡去找，带回 3–5 张石卡。每张结果卡上标出它是哪张槽卡贡献的。你留下或丢掉，留下的那张，它背后那几张槽卡的属性各记一次"使用"。这就是升金的燃料：**卡放在槽里被用，比放在口袋里被看，更快变金。**

### 9.4 融合

把一张卡拖到另一张上，或者 Sense 在整理时提示"这三张可以融合"。融合要求卡之间至少共享一条属性。

| 投入 | 产出 | 例子 |
|---|---|---|
| 3 张同属性的关注卡或收藏卡 | 1 张银色兴趣卡 | 三部都挂「要有谜底的世界」的番 → 兴趣卡"谜底型世界" |
| 判断卡 ＋ 金句卡（同属性） | 这条属性被确认，判断卡升银 | 「实装到底，发布要等我看过」＋ 你说过的「撤回也会留下记录」 |
| 人物卡 ＋ 收藏卡（他的论文或仓库） | 人物卡升银，"为什么在意"一栏自动填上 | 一位作者 ＋ 你截的他论文里的一段 |
| 2 张银卡 | 1 张金卡候选，你确认才成金 | — |

融合不删原卡。原卡叠在新卡下面，点开能看到，作为证据。这条和苏丹的游戏不同，因为 Sense 的证据要可溯源。

### 9.5 委托（苏丹卡）

Sense 每周发一到两张委托卡，每张带格子和期限，放对的卡才能开：

| 委托 | 格子 | 期限 | 完成后 |
|---|---|---|---|
| 本周补番 | 3 张关注卡 | 7 天 | 每部出一张"上次看到哪、新的是什么"的更新 |
| 想联系一个人 | 1 张人物卡 ＋ 1 张判断卡 | 7 天 | 一封 cold mail 草稿，发不发你定 |
| 这条属性还对吗 | 1 张你最近丢掉的卡 ＋ 1 张金卡 | 3 天 | 属性被确认、改写或降级 |
| 整理口袋 | 5 张 30 天没动的铜卡 | 7 天 | 留、融合或归档 |

过期不惩罚，委托消失，下周换一张。委托的作用是让你每周有一个打开口袋的理由，而不是考核。

### 9.5a 抽卡做 survey

作者 2026-10-21："卡比较多的时候，可以抽卡来做 survey。"

口袋大了以后，你不会一张张翻。Sense 像小丑牌发手牌一样，从口袋里抽一手卡，每手问一个很快能答的问题。答案直接写回属性和品级。

**什么时候抽**：口袋里铜卡和银卡超过 50 张后开放；你按"抽一手"，或者作为每周委托里的一张。

**一手**：5 张，一分钟内答完。不想答这一手可以弃掉重抽一次，同小丑牌的弃牌。

**抽哪几张**（加权，不是纯随机）：

| 优先抽 | 为什么 |
|---|---|
| 挂着候选属性、还没被确认的卡 | 确认属性是升银升金的前提 |
| 快要归档的铜卡 | 最后问一次还要不要 |
| 两条属性互相打架的卡 | 例如 M0 里"不要 mock"和"暂时 mock 一下" |
| 1 张金卡 | 对照组，看你的口味有没有变 |
| 1 张随机 | 防止只问 Sense 以为重要的 |

**问法**：

| 问法 | 抽几张 | 你做什么 | 写回什么 |
|---|---|---|---|
| 还在意吗 | 1 | 留 / 丢 | 品级升降，属性用次加减 |
| 二选一 | 2 | 挑一张更像你的，可选说一句为什么 | **对照**：被放弃的那张就是对照，你那句话就是理由。这是补齐判断四要素最快的办法，日志里最缺的就是这个 |
| 排个序 | 3 | 从左到右排 | 属性的相对权重，决定 agent 卡槽里谁放左谁放右 |
| 是同一个东西吗 | 3 | 是 / 不是 | 是：提示融合；不是：拆开属性 |
| 哪张不属于 | 4 | 挑出不一样的那张 | 属性的边界：那张为什么不算，写成属性的"不包括" |

**和门槛的关系**：survey 的结果也是第 4 节调门槛的信号。你在 survey 里频繁丢掉金卡，说明门槛太低；频繁留下快归档的铜卡，说明太高。

### 9.6 感觉

- 像素卡面，七种类别各一套边框和底纹，品级换边框材质：石是灰岩、铜是铜锈、银是亮银、金是流动的金。
- 卡放进槽、结果冒分数、融合合成，都要有短动画和音效。融合的那一下要有分量。
- 口袋是手牌，agent 卡槽是牌桌，委托是摆在桌边的苏丹卡。
