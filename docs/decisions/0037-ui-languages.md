# 0037 · 桌面版界面有中文、English、日本語

日期：2026-10-25 · 状态：已定

## 作者说的
> 我们现在的桌面上，它那个 Sense 这个平台里面，它没有这个英语日文的这个两个选项，你可以改一改。

选项里选了：通话语言、整个 app 的界面语言都要。

## 规则
- **两个开关**：界面语言（设置最上面、桌宠菜单里）和通话语言（桌宠菜单里一排「中文 / 日本語 / English」）。第一次选界面语言时，通话语言跟着它；之后各管各的。
- **只翻界面，不翻你的东西**：卡的标题、正文、证据、属性、她知道的事、你写的话，原样显示。「」『』《》里的东西不翻（那是卡名、作品名）。
- **新生成的文字跟界面语言**：切到 English / 日本語 之后，agent 新写的介绍、问题、委托用那个语言写；已经有的不回头改。
- **做法**：界面文字在代码里保持中文（很多字同时是协议，比如通话标记里的卡种名），显示时按 `m0/i18n/<lang>.json` 换成对应语言；没翻到的字就显示中文，不报错。`app/scripts/i18n-extract.mjs` 从源码里抽出所有界面文字，新加的字跑一次补进表里。
- 画在图里的字（海报、像素卡面）暂时只有中文。

## 补充（2026-10-25）：通话语言隔离、男版通话

- 问题：切到英语 / 日语通话，系统提示仍是中文（soul、规矩、摘要），角色时不时冒中文；切到男版，通话还是用女版的 soul 和女声。
- 改法：
  - 每个角色的 soul 有中文正本和英、日译本（`soul.en.md` / `soul.ja.md`）；成长层的标题、口袋摘要、通话规矩也按通话语言整份写。
  - 只有两样保持原样：标记（〔卡 …〕等，给程序读，不念）和作者自己的内容（卡名、原话、记忆）。规矩里写明「这些可能是中文，说的时候用通话语言自然地说，不要念中文」。
  - 男版 `claude-m`、`deepseek-m`、`pouch-m` 有自己的 soul 和三门语言的声音；男版开着时，通话用男版。
  - 声音：男版三门、女版日英由作者 2026-10-25 试听后选定；女版中文沿用原来那个。
