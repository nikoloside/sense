# 0012 · Sense 的定义：四要素，三层次

日期：2026-10-20 · 状态：已定

## 决策
sense = 在一堆选项里认出"就是这个"的能力，以及说得出为什么。由场、选择、对照、理由四要素构成；没有对照的判断只是兴趣，不能升为 confirmed。
sense 有三层：潜在（藏在选择里）→ 显性（带四要素的判断，用户确认过）→ 生成（到新的场里替你选并说出为什么）。产品的工作是把一个人的 sense 从第一层推到第三层。

## 原因
- v1.0 的 Judgment 有证据、条件、理由，缺"对照"，于是"喜欢机制清楚的论文"和"关注 X 方向"分不开。
- 用户 2026-10-20 的 superconnector 经历（表格里一堆人，只对一个起念）说明 sense 只在对比里可见。
- 三层对应四步体验，也给三种卡片以边界。

## 影响
SENSE.md 第 1 节重写；Judgment 加 scene / choice / contrast；schema 待同步；三层各一种卡（0013）。
