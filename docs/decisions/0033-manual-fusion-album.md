# 0033 · 手动融合；融合默认不升级；融合卡是相册

日期：2026-10-23 · 状态：已定 · 修订 7.5.7（融合），补充 0022

## 作者说的
> 我现在能手动融合吗？他的推荐我不喜欢，还有，融合之后，图片可以探索到一个地方，融合之后也不一定要成为金

选项里选了：融合卡像一个相册；默认不升级，可选成金。

## 规则
- **手动融合**：每张卡（石、铜、银、金）上都有「融合…」。打开后这张已选中，可以从口袋里再挑，至少两张，石卡排在最后；能改融合卡的名字。不要求共享属性，作者挑的就是证据；有共享属性就挂上，没有就挂原卡里用得最多的属性。
- **Sense 的融合建议**照旧按共享的已确认属性算，打开后同一个面板，可以去掉、也可以再加卡。
- **石卡也能融合**（作者问「为啥不能融合石头卡？」后补）：挑石卡去融合本身就是「我在意它们」的决定。融合出的卡至少是铜卡；石卡叠在下面后不会再碎。
- **品级**：默认取投入里最高的品级，至少铜。勾「成金：这是一种口味」才成金卡，投入全是银卡或金卡才能勾。0022「金卡只能由银卡融合」仍然成立，只是不再自动。
- **相册**：融合卡没有自己的图时，卡面拼原卡的图（最多四张）。点开融合卡，上面是一个可以左右翻的相册，一张张看原卡的图和标题，点图进那张卡。
- **拆开**：任何融合卡都能拆开（以前只有金卡能拆）。
- 奖励照 0032：每少一张 +10 XP，成金再 +50。
