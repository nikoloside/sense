# 0001 · 品牌名用 Sense，定位用 Personal Taste Agent

日期：2026-10-20 · 状态：已定

## 决策
产品叫 **Sense**，一句定位 **Your personal taste agent.**。不拆成 Taste Agent 和 Sense Agent 两个产品。

## 原因
- Taste Agent 内容明确但作为品牌直白，且容易被理解成只做艺术、穿搭、影音。
- Sense Agent 范围宽，但英文里不一定联想到品味，也可能被读成感知环境的技术模块。
- Sense 单独作品牌名，日文「センス」贴近审美和品味；能力用 Taste 解释即可。
