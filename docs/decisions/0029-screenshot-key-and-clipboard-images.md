# 0029 · 截图键换成 ⌃⇧⌘A，并能收剪贴板里的截图

日期：2026-10-23 · 状态：已定 · 修订 0020（⌃⌘A 截图）

## 问题
- 原来的截图键是 ⌃⌘A，和微信 Mac 版的截图键相同。两个 app 都注册时，macOS 不报错，按键被先注册的那个吃掉。微信开机就在，所以按 ⌃⌘A 出来的是微信的截图。
- 加上「截完也复制到剪贴板」以后，Sense 的截图一次都没跑过。Sense 只在终端打了一句，界面上没有任何提示。

## 决策
- **B：Sense 自己的截图键**
  - 默认 ⌃⇧⌘A，和系统的 ⌃⇧⌘3 / ⌃⇧⌘4（截到剪贴板）是一类组合。
  - 在「入口 → 截图」里点「换截图键」，直接按新组合：至少两个修饰键，其中要有 ⌃、⌥ 或 ⌘。
  - 换的时候先注册新键，成功了再放掉旧键；新键注册不上就保留旧键，并说明原因。
  - 截完的图照旧进口袋，同时复制到剪贴板，在主线程写。
  - 菜单栏和快捷菜单里的「截图进口袋」按钮不需要快捷键，永远能用。
- **A：收剪贴板里的截图**
  - 用别的工具截图（微信 ⌃⌘A、系统 ⌃⇧⌘4、飞书）时，剪贴板是那个工具写的，所以 ⌘V 一定能贴。
  - 打开「收剪贴板里的截图」后，剪贴板里一出现新图，就问一句要不要放进口袋。问的地方：主窗口右下角、快捷菜单顶部、桌宠头上冒「!」并说一句。
  - 点「放进口袋」才收，走和截图一样的认图建石卡流程。证据写「截图 · 剪贴板里收的（当时在某 app）」。
  - 点「不要」或 3 分钟不理，图就丢掉，什么都不留。
  - 只收图片本身：Finder 里复制的文件、带密码管理器标记的内容、Sense 自己放进去的图都不问。
  - 不看图片来源是哪个 app，因为微信截图的来源就是微信。文字流水那份「聊天 app 不记」的名单只管文字。
  - 默认关，和文字剪贴板流水是两个开关。

## 原因
- 不和任何 app 抢截图键：你用惯哪个截图就用哪个，Sense 只是旁边问一句。
- 只有你点了才收，和「原始内容不入库」一致。
