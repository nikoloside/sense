# 0024 · 新卡标记与碎卡

日期：2026-10-22 · 状态：已定 · 修订 0022 的石卡归档规则

## 决策
- **新卡（NEW）**：一张卡从没被你处理过，就挂 NEW。处理指打开、留下、丢掉、跟、放上追踪台，也就是任何一次 touch。
  - 口袋的标签上显示 NEW 的数量。
  - 筛选栏有「NEW 没处理过」，可以只看这些卡。
  - Sense 页的行里也标 NEW。
- **碎卡**：石卡如果一次都没处理过，从第一次见到算起 7 天后会碎（截图 30 天）。
  - 碎前 2 天（截图 5 天）卡面出裂纹，标「还剩 N 天」或「今天碎」。
  - 在追踪台上的不碎。
  - 碎卡进仓库的碎卡堆：只留标题、类别和来源，可以「捡回来」变回石卡，重新计时。
- **处理过的卡照旧归档**：处理过、但 7 天没再碰的石卡，以及 60 天没碰的铜卡，进仓库的归档区。这一条和以前一样。
- **碎卡的用处是「查到过」这条记录**：
  - 整理和推荐靠它去重，不会把同一样东西再塞进来。
  - 品味整理的 prompt 会附上碎卡清单，写明「他没理会，不要再列，也不要因此认为他讨厌」。
  - 碎卡不会降低属性，也不算反对证据。没理会不等于不喜欢，这和跨领域只提问是同一个原则。

## 原因
作者 2026-10-22："新卡里面找不到，有些卡一次都没处理过，我们其实可以找到新卡标记"；"石头卡没有处理过的话，放在仓库里面会自己碎掉……查到记录，但是不太在意的话，就会有一个碎卡的逻辑"。

## 修订（同日）：早碎
- 作者："可以有早碎的逻辑"。
- **被比下去**：没处理过的石卡在抽卡「二选一」里输了，耐久少 3 天，记在 `wear`。少到期限以下就当场碎。这条只对没处理过的石卡生效，赢的那张算处理过。
- **亲手碾碎**：石卡的详情里有「碾碎：不太在意」，点了立刻碎，有碎片动画。和「丢掉」不同：丢掉是明确不要，会让属性用次 −1；碾碎只是不在意，不动属性。
- 碎卡捡回来时，耐久清零，重新计时。
- 同日的界面改动：头部换成主题色的色带（各主题有 `--hdr*` 变量）；macOS 标题栏改成 Overlay，红绿灯按钮放进头部，头部可以拖动窗口；App 图标和头部的小口袋换成新的像素口袋（插着一张金卡和一张银卡）。
