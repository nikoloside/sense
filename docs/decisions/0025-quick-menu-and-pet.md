# 0025 · 快捷下拉菜单与桌宠

日期：2026-10-23 · 状态：已定 · 补充 0020（菜单栏图标）

## 决策
- **快捷下拉菜单**：菜单栏图标左键、口袋头部右上角的小口袋、桌宠，三个入口点开的是同一个下拉菜单。菜单栏图标右键仍是原生菜单（打开口袋 / 截图 / 退出），作为兜底。以前左键是直接显示或隐藏主窗口。
- 菜单从上到下：
  1. **角色条**：Lv、称号、职业、卡数、XP 条，颜色跟主题的头部色带。
  2. **引擎一行**：在转时写下一个座位和时间；正在跑时写在查哪张卡，或者正在整理品味；暂停时写「暂停了」。
  3. **三格计数**：NEW 新卡、快碎了、任务可领，点一下跳到口袋的 NEW 筛选或设置页。
  4. **快碎了**：最多 3 张，写还剩几天，点开就是那张卡。只有在有卡快碎时才出现。
  5. **快捷动作**（2×3）：截图进口袋、抽一手、剪贴板开关、桌宠开关、引擎暂停或继续、现在整理品味。
  6. **配色**：五个色块，点了直接换。
  7. **底栏**：打开口袋、设置、退出。
- **桌宠「口袋精」**：一个透明、置顶、所有桌面都在的小窗。
  - 身体颜色跟主题色，戴着设置页里角色职业的帽子。
  - 第一次打开默认放出来，在主屏幕右下角。拖走后记住位置。可以在菜单或设置页里收起来。
  - 它只演口袋里真发生的事，不演假的：
    - 进卡（截图、整理、推荐）→ 张嘴吃，气泡写卡名。
    - 碎卡 → 抖一下。
    - 开始关注、领任务、融合 → 跳一下，冒星星。
    - 引擎在跑 → 拿放大镜，眼睛往上看。
    - 引擎暂停 → 睡觉。
    - 有卡快碎或任务能领 → 头上冒「!」；有卡快碎时，每 40 分钟提一句。
  - 交互：单击弹快捷菜单，双击打开口袋，按住拖动，鼠标移上去显示 NEW、快碎、任务的数。
  - **喂食**：把图片拖到它身上，等于截图进口袋。走同一条认图建石卡的路；最多 5 张；只收 png、jpg、gif、webp；不切走你正在看的页面。
- **只有主窗口写状态**：菜单和桌宠是另外两个窗口，它们只收主窗口推来的摘要（`sense://summary`），按钮把命令（`sense://cmd`）发回主窗口执行。所以 pocket-state.json 仍然只有一个写入方。
- 摘要里只有计数、标题、等级和引擎状态，不含证据和原文。

## 原因
作者 2026-10-23："我们现在右上角的快捷下拉菜单并没有，而是直接切换窗口，可以有下拉菜单，然后可以设计一下下拉菜单是什么，还有桌宠也可以加上"。

## 影响
- `app/src-tauri/src/lib.rs`：菜单定位与开关、桌宠窗口、拖图片喂食。
- `tauri.conf.json`：menu、pet 两个窗口；`macOSPrivateApi` 打开，透明窗口需要它。
- `m0/menu.html`、`m0/pet.html`：配色由 build-ui 从主模板的 THEMES 段拷入。
- `m0/pocket.template.html`：summary、onCmd、log 喂桌宠、头部小口袋变按钮、设置页桌宠开关。
- `S.pet = {on, x, y}`。
