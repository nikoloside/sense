# 0018 · 主面是口袋 app；自带截图即建卡；剪贴板、邮件进入口；浏览器履历全部扫

日期：2026-10-21 · 状态：已定 · 修订 0013 的"两个面"；修订 SENSE.md v1.1 7.1 的路径包含规则

## 决策
- v1 主面是 macOS 的口袋 app：所有卡在一个口袋里，好检索（搜索框 ＋ 类别 / 品级 / 属性三个筛选）。iOS v1 只走分享菜单。CLI 降为引擎与调试面。MCP 仍按 0013 在 v1.1。
- app 自带截图：全局快捷键框选，松手即生成一张石卡，Sense 自动认类别、挂属性或挂到已有的卡上。截图是 v1 第一个做的入口。
- 剪贴板进入口：记内容、来源 app、粘贴去向；粘进 agent 的只作会话上下文。按 SENSE.md 7.1.1 在读取边界跳过密码管理器标记、敏感 app、聊天与邮件来源、密钥样式内容。
- 邮件进 v1：人物卡读收发双方、主题、日期与用户自己写的正文；别人写的正文不存。
- 浏览器履历全部扫，只排除别人的 profile 与登录、支付、银行、医疗、签证、后台类页面；按频次出卡，不出判断卡。

## 原因
- 作者 2026-10-21："卡和收藏的 APP 可以做得好一点"；"做成口袋，和比较好检索的一个 UI，自带一个截图的工具，截图完了之后自动作为一个生成卡的动作"；"复制剪贴板里面的东西都是我们的 context"；"人物卡读 email 和其他"；"不应该全部扫么？"。
