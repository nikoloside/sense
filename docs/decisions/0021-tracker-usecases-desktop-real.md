# 0021 · 追踪台、用例卡；桌面版里的按钮全部实装

日期：2026-10-22 · 状态：已定 · 细化 0018、0019、0020

## 决策
- **追踪台**：口袋里多一张一直在转的桌子（6 个座位）。放上去的卡按作者定的节奏（每天 / 每周 / 每月）自己跑，三种模式可叠加：
  - 定期更新：联网查"上次看到之后"有没有新一话、新作、新刊、新论文。查到就出一张挂在原卡上的石卡（subkind `update`），并记下新的进度。
  - 挖信息：围绕这张卡联网找 2 到 3 条相关的东西，作者留下的成推荐卡。
  - 自动出题：把这张卡排进抽卡，下一手先出它。
  app 开着时每 30 秒看一次有没有到期的座位，一次只跑一个；关掉时不跑，下次打开先补。
- **用例卡**：作者想让 Sense 做的事也是卡。三种：
  - 派 agent：原牌桌上的 agent。
  - 委托：原 0019 的委托。
  - 作者自己写的一句话。
  用例里放卡，按「做」就真的做（联网查、写草稿，不替作者发送）。用例也能放上追踪台定期跑，例如"每月看海贼王进度"。原「委托」页并入「用例」。
- **入口页**集中所有进口袋的路：
  - 截图（⌃⌘A）。
  - 剪贴板（默认关，作者打开后才记）。
  - 浏览器履历与书签。
  - 电脑上的文件：只看文件名，外加 Steam 游戏。
  - 会话日志：派 agent 去读。
  - 邮件：还没接。
  扫出来的先当候选，作者点「收」才进口袋，不要的不再出现。
- **桌面版里没有假按钮**：
  - 出一手不再退回预先算好的结果，失败就如实报错。
  - 委托完成时真的生成奖励。
  - catch up 真的去查。
  - 去掉"复制操作记录"：状态文件本身 Claude Code 就能读。
  网页版保留预先算好的一手，只当演示。
- **桌面版调用 agent 的方式**：调本机 `claude -p`。
  - 参数：`--no-session-persistence --strict-mcp-config`，在 `~/Library/Application Support/Sense/agent` 里跑。
  - 只放行这次要用的工具：联网用 WebSearch / WebFetch；认图和读日志用 Read / Glob / Grep，读日志时加 `--add-dir`。
  - 这仍是 0014 / 0020 的"引擎在 Claude Code"，只是由 app 发起。
- **剪贴板的去向**：不监听按键（需要"辅助功能"权限），改记"复制后 10 分钟内第一个切到的 app"，页面写作"之后切到"。这是 7.1.1 的降级实现，粘贴动作本身抓不到。
- **Sense 页顶部加展示卡**：一张 720×1040 的像素海报，内容是分岔、属性、金卡，可存成图片。

## 原因
- 作者 2026-10-22："然后把这个我们的 Sense 展示页面做出来。然后每张卡片，我们的任务其实就是我们的 use case 可以作为卡片去做出来"；"那个时刻在转……你只要把卡放上面，它就开始自动做 survey 也好，自动去挖信息也好，自动去定期去更新。比如说……每个月看到说它这个剧更新了，就这种追番的那种体验"。
- 作者 2026-10-22："现在我们的 mock 的按钮有点多，可以直接全部实装，然后用 tauri app 做"。
