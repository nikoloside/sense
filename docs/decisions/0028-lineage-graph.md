# 0028 · 卡片谱系图

日期：2026-10-23 · 状态：已定 · 补充 0022（品级分工）、6.10 Card

## 决策
- 点开任何一张卡，详情里有一块「谱系」：以这张卡为中心的家谱式分层图。
  - 上面是来路，下面是它生出的，各展开 2 代。
  - 一张卡亲戚都没有时（只有来源、没有任何相连的卡），不显示这块。
- **只画数据里已经记下的关系，不让 Claude 去猜。** 线的种类：

| 线 | 方向 | 字段 |
|---|---|---|
| 来自 | 来源 → 卡（Claude Code 对话、品味整理、截图、追踪台、抽卡等），只画中心卡的、最多 2 个 | `evidence[].where` 的前两段 |
| 融合 | 原卡 → 融合出的卡（金卡，或抽卡时合并的卡） | `fused_from[]` |
| 推荐 | 金卡 → 它推荐出的铜卡 | `from_gold` |
| 更新 / 挂上 | 卡 → 追踪台查到的更新卡；卡 → 截图时挂上去的卡 | `attached_to` |
| 留下 | 追踪台座位（卡或用例）→ 你在那里点「留下」的铜卡 | `from_track`（新增） |
| 像 | 金卡底下的原卡 → 金卡推荐出的、说「像它」的铜卡 | `like_id`（新增） |
| 同属性 | 卡 — 卡，虚线 | `attribute_ids[]` 有交集 |

- **同属性默认折叠**：中心那一行左右各放 2 张，其余收成「+N」。点开后，全部按格子排在图下方，不连线，免得成毛线团。
- 每代最多画 5 张，再多的写「还有 N 张」。
- 节点是小卡面：边框是品级色，左侧色条是类别色。来源节点是虚线框。
- 碎掉或归档的卡也画，但变淡，因为谱系是历史。
- 点任意卡节点，图就以它为中心重新展开；上面有「← 回到 …」一路退回。
- 用内联 SVG 自己画，不引外部库。
- 新字段只从现在开始记，旧卡不回填。旧的金卡推荐只有一句「像『X』」的文字，没有 id。
- **这次不做**：整个口袋的全局关系图。

## 原因
- 卡片之间的生成关系已经存在（银卡查出更新、金卡推荐铜卡、融合），但详情页只显示「叠在下面的原卡」，看不出一张卡从哪来、又生出了什么。
- 只用已经记下的关系，谱系就是可溯源的事实，和「判断必须能溯源」一致。
- 同属性关系是软关系，数量也大（一条属性常连着十几张卡），所以默认折叠。
