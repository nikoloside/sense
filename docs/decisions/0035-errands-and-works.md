# 0035 · 派活：写、画、查、整理，产出成「作品卡」

日期：2026-10-25 · 状态：已定，已实装（2026-10-25）· 补充 0034

## 作者说的
> 以及可以做点别的工具……比如说写小说啊，生成图片给我看，或者说可能就是让它帮我做点事情。

选项里选了：产出放进口袋，新加一种「作品」卡；出图接一个出图服务；第一版只产出、不碰外面。

## 规则
- **怎么派**：通话里说，或者在口袋里点「派活」打字。角色嘴上应一句，写一个不念出来的标记〔活 种类|要做什么〕，后台交给 agent 去做；通话照常聊，不等它。
- **能做的四种活**
  - 写：短篇、诗、故事续写、一封邮件的草稿（只起草，不发）。
  - 画：一张图。走出图服务；钥匙填在 config.json（`image_api_key`），没填就说「还没接出图服务」，不偷偷换成别的。
  - 查：一个题目查透，出一页带出处的小报告。
  - 整理：拿口袋里的卡做清单、时间线、比较表。
- **作品卡**（第八种卡）：标题、做的人（哪个角色）、派活的那句话、产出（全文 / 大图 / 报告）、用到的出处。点开看全文或大图，像相册那样能翻同一件活的几版。文件同时存一份到 `~/Documents/Sense/作品/`，方便拿去别处用。
- **品级**：作品卡进来是石卡，你留下才成铜；它是角色的产出，不是你的品味，**不进品味档案、不挂属性**，除非你自己在卡上点「这个像我」。
- **边界**：只产出。不发消息、不付款、不登录、不改本机其他文件、不装东西。要动外面的事，它只起草，告诉你去哪里点。
- **成本**：出图每张都要钱，每天上限（默认 10 张，可调）；超了它嘴上说「今天的画额度用完了」。
- 做完桌宠举手「作品做好了」，点气泡进那张卡。

## 实装时定下的（2026-10-25）
- 出图服务：作者选了 OpenAI gpt-image-1（1024×1024，medium）。钥匙只从本机 config.json 读，经 curl 的标准输入传进去，不出现在命令行和日志里。
- 通话里的标记是〔活 写|…〕〔活 画|…〕〔活 查|…〕〔活 整理|…〕；一起编故事时说「画出来」走〔活 画|这个场面〕。
- 作品文件放在做它的角色的 `characters/<id>/works/<作品 id>.md|png`（0036 的 works/），另存一份到 `~/Documents/Sense/作品/`。卡里只存缩略图和路径，不把大图塞进口袋状态。
- 「再做一版」把新版本挂在同一张作品卡上，翻页看；失败的活留在口袋页「派活」那一栏，可以再试或算了。
- 作品卡不出现在融合建议和追踪台按钮里（它不是你的品味）。
