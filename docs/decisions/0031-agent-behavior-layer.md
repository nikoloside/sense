# 0031 · 定位：Sense 是一层 agent 行为框架，品味是中间那层抽象

日期：2026-10-23 · 状态：已定 · 补充第 1 节（Sense 是什么）；不改闭环和数据模型

## 作者说的
> Sense 是一组把我们的日常行为、兴趣爱好、日常喜好，都抽象成一组行为固定下来的 Agent 行为层框架。它努力把我们平时行为和动作抽象成「品味」，然后它可以是一个行动，可以是一个关注，可能是一个信息。
> 比如说，我想要给一个朋友发 cold email，然后关注他的变化以及和这个人的关系；比如说，我们的一个目标，check 我们的行为习惯；比如说，我们的一个兴趣爱好，可以一直 check 这个偶像、这个电影的新闻消息。
> 目前它只是 desktop，它可以是一个手机，也可能是一系列新的行为，可以 customized 我们的习惯行为。

此前对外写成「Sense 是一组替你干活的 agent，由口袋里的卡决定」，作者否了：方向反了。卡是品味的载体，不是 agent 的驱动器。

## 定下来的说法
- **一句话**：Sense 是一层 agent 行为框架：把你的日常行为、兴趣和喜好抽象成「品味」，再把品味固定成一组会自己运行的 agent 行为。
- **四步**：看你的行为 → 抽象成品味（每条带证据，口袋里是一张卡）→ 把品味固定成行为 → 你来调规则（石铜银金、留下 / 丢 / 碾碎 / 跟 / 融合）。
- **品味固定成的行为有三种**：
  - **行动**：替你做一件事（例：起草一封 cold email）。
  - **关注**：定期去看它的变化（例：这个人最近在做什么、你们的关系走到哪了）。
  - **信息**：查到新的就告诉你（例：偶像、电影的新闻）。
- **三个起点的例子**：一个人（cold email ＋ 关注变化与关系）、一个目标（定期 check 行为习惯）、一个兴趣（一直盯着偶像 / 电影的新闻）。
- **形态**：现在是 macOS 桌面版；以后可以是手机，也可以是一系列新的行为；习惯行为可以自己定制，做成游戏（等级、委托、像组卡组一样配 agent）。
- **标语**：英文仍是 "Your personal taste agent"，副标题 "An agent behavior layer built from your taste"。中文副标题：把日常抽象成品味，让品味变成会自己运行的 agent 行为。

## 和现有定义的关系
- 第 4 节闭环、第 6 节数据模型不变：Evidence → Judgment（属性）→ Card 仍是「抽象成品味」那一步；7.8 G 环（跟踪、整理、出一手）就是「固定成行为」的现有实现：银卡的跟踪 = 关注，追踪台上的更新 = 信息，用例和出一手 = 行动。
- 「一个目标 → check 行为习惯」现在由追踪台上的决定卡承担（到点查一次进度）；专门的习惯检查是后续工作，不是 v1 范围。
- 自定义行为 / 游戏化、手机端：方向，不进 v1 范围。
