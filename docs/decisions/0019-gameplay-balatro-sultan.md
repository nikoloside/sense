# 0019 · 玩法参照《小丑牌》与《苏丹的游戏》：agent 卡槽、融合、委托、抽卡 survey

日期：2026-10-21 · 状态：已定

## 决策
- 每个 agent 有 4 个卡槽，第一张金卡出现时解锁第 5 个。左约束、中对象、右口味，从左到右结算；第 5 槽是 Sense 放的野卡，往盲区找。部分组合有邻接效果（人物卡 ＋ 判断卡 = 起草 cold mail）。
- 出一手：一句话 ＋ 槽里的卡，agent 带回 3–5 张石卡，每张标出由哪张槽卡贡献；留下的结果给这些槽卡的属性各记一次使用。
- 融合：共享属性的卡可合成更高品级的卡，原卡叠在新卡下当证据，不删。
- 委托：每周一两张带格子、带期限的任务卡；过期不惩罚。
- 抽卡 survey：口袋里铜银卡超过 50 张后，抽 5 张问一个快问题（还在意吗 / 二选一 / 排序 / 是同一个吗 / 哪张不属于）。二选一补对照与理由。
- 像素卡面，品级换边框材质；放卡、结算、融合要有动画与音效。

## 原因
- 作者 2026-10-21："按照 Joker 卡牌游戏或者苏丹的游戏一样，去设置这个卡片的感觉和游玩机制，以及卡片可以融合，以及卡片可以放在卡槽里面，agent 可以有 4–5 个卡槽"；"卡比较多的时候，可以抽卡来做 survey"；"可以可以"。
- 卡槽把"透镜"（SenseContext，6.6）变成用户摸得到的东西：放什么卡，agent 就带着什么 sense 去找。
