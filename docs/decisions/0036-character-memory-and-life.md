# 0036 · 角色有自己的记忆和经历：边聊边记，自己去读、去画、去查，长出主见

日期：2026-10-25 · 状态：已实装（三步都做完）· 补充 0030（角色与语音）、0034、0035

## 作者说的
> 一边聊天他一边能记忆……他自己的 Folder，然后我们这边的 Context 也可以成为他记忆的一部分……他自己可以有一些主动的行为……在聊这个故事过程中，可以去考虑这个逻辑怎么样……让他去读一些故事，或者让他自己去画画……不断去搜索，然后可以丰富自己的人格，以及有自己的主见……有点像 RP，或者说我们可以一起玩 RP……让他经历一些事件，然后我们最后有一些活动，有些方式方法能够加载这些东西。

选项里选了：女版男版各自一份记忆；每天自己做一件活动（画图每天最多一张），你也随时能叫；挂断后直接记、可查可删；先做记忆，再做活动和派活。

## 分三步做
1. 角色文件夹、边聊边记、接通时加载、一起编故事。
2. 作品卡、派活、出图（0035）。
3. 她自己的活动和主见。

## 照 soul 的写法（作者补充：「记忆系统做的方式，你可以参考我们的 Soul 的方式去记」）
沿用角色文档规约（worldlines-characters `docs/SCHEMA.md`）的分法，不另起一套说法：**正本**（人设）和**知识**（她通过经历、观测、传闻知道了什么、什么时候知道的）分两份。正本不因经历改写；知识从她的经历生成，每条都写明渠道和日期。文件都是带 frontmatter 的 Markdown，Markdown 为准。

## 两层人格
- **正本**：仓库里的 `characters/<id>/soul.md`。外貌、性格底色、说话方式、不做的事。不会被经历改写，所有人拿到的都一样。
- **成长层**：本机的角色文件夹（下面）。她经历过什么、记得你什么、自己怎么看。只在你的电脑上，不进仓库、不上传，只在调用模型时作为上下文发出去。

## 角色文件夹
`~/Library/Application Support/Sense/characters/<id>/`（女版男版各一份：`claude`、`claude-m`……）

| 文件 | 是什么 | 谁写 |
|---|---|---|
| `knowledge.md` | 她知道的事（分「关于他」「关于世界」「想问他的」三节）：一条一句，带日期和来源（「10-25 通话」「口袋：来自深渊」） | 每通电话挂断后她自己写；挂断清单里列出「她记住了…」，不对的点掉；口袋里能看、删、清空 |
| `diary/YYYY-MM-DD.md` | 她的经历：读了什么、画了什么、查了什么、和你聊了什么故事，每条带出处 | 每次活动后她自己写 |
| `opinions.md` | 她的主见：一条一个看法，写明从哪次经历来的、为什么 | 活动后她可以加、改；每条都必须指向日记里的一次经历 |
| `stories/<名字>.md` | 和你一起编的故事的设定集：人物、世界规则、到目前为止的情节、没填的坑 | 一起编故事时她维护 |
| `works/` | 她的作品（0035 的产出也放一份） | 派活 / 她自己的活动 |

口袋本身也是她记忆的一部分：每次接通照旧带口袋摘要（0030），不重复抄进她的文件夹。

## 记什么、不记什么
- **边聊边记**：通话中双方说的话只留在内存里；挂断时交给 agent 整理成几条写进 `knowledge.md`（和故事进展写进设定集），然后内存里的全文丢掉。通话全文仍然不落盘（原则不变），只存整理出的那几句。
- 她记的是「她对你的了解」，**不等于你的品味档案**：要进口袋的东西走 0034 的记卡标记，你说了算。
- 跨领域推测只能写成「想问他的事」，下次聊天时问，不能记成事实。
- 别人的真名、别人说过的话：不记。
- 你在口袋的「她记得的事」页面能逐条看、改、删，也能整份清空。

## 她自己的经历（活动）
- 四种活动：**读**（读一篇公开的小说、文章、作品介绍，或你口袋里某张卡指向的东西）、**画**（走 0035 的出图服务）、**查**（她好奇的题目）、**想**（回看最近的日记，修改一条看法）。
- 题目从哪来：你聊天里提到的、你口袋里在跟的、她自己日记里没想通的。不碰你的私人资料（规矩同浏览器扫描）。
- 每次活动写一篇日记；可能加一条看法；可能出一件作品（作品卡，标「她自己做的」）。
- 有上限，花的是你的调用和出图额度（默认见下方问题）。

## 主见
- 她可以不同意你、可以有自己喜欢的东西，但要说得出「我读了 X 以后这么觉得」。说不出来源的看法不写。
- 不为讨好你改看法；你说服了她，她会在 `opinions.md` 里改，并记下是哪次对话改的。
- 正本里「不夸你的品味、不打分」照旧：她对作品有主见，不对你下评语。

## 主动
- 接通时，她可能先开口说一件她最近经历的事（「本小姐昨天读了……」），一通电话最多主动提一次。
- 活动出了作品，桌宠举手，气泡说一句，点开进作品卡。
- 不主动给你发任何消息，不主动打电话。

## 一起编故事 / RP
- 通话里说「我们来编个故事」或「来玩 RP」，进故事模式：她按 `stories/<名字>.md` 接着讲，注意前后逻辑（人物动机、世界规则、前面埋的坑）；你说的设定她当场记进设定集。
- 「先停一下」回到平常聊天；下次说「接着上次的故事」能接上。
- 讲到一个场面，可以说「画出来」，走出图，图进作品卡、也挂进设定集。

## 怎么加载（上下文预算）
每次接通，系统提示 = 正本 ＋ 口袋摘要（已有）＋ 成长层摘要：
- `knowledge.md` 里最近的、和这次话题相关的若干条；
- 最近三篇日记的标题和一句话；
- `opinions.md` 最常被提起的若干条；
- 在故事模式时，再加那个故事的设定集。
超出预算时按「最近 + 被提起次数」截断。之后再做按话题检索。

## 实装记录（第三步，2026-10-25）
- 四种活动都是一次 agent 调用：读、查带 WebSearch / WebFetch；想不上网；画先出描述再走 0035 的出图。只回 JSON（题目、日记、出处、看法、可选作品）。
- 自动：每个角色每天一次，条件是 Sense 开了 15 分钟、没在通话、没有别的 agent 在跑、引擎没暂停；设置 →「角色自己的活动」可关。手动：「她知道的事」页面的「让她去读 / 查 / 想 / 画」。
- 画：她自己每天最多一张，同时算进每天的出图上限；没接出图服务就不选画。
- 日记条目标「（自己做的）」，带出处和作品编号；看法每条带「来由：日期 日记 · 那件事」，改旧看法时附「改自：旧看法」。
- 接通时带上最近一条「自己做的」日记，系统提示里说可以先提一句、一通电话最多一次（三种语言都有）。
- 作品卡 `via: self`，卡上写「她自己想做的」；查到的东西只有她觉得值得才出报告作品，不然只进日记。
