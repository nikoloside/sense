# 0014 · 引擎由 agent 执行，早期宿主是 Claude Code；来源以会话日志为先

日期：2026-10-20 · 状态：已定

## 决策
- Sense 的 A、B 环（收集 context、提炼判断）由一个 agent 按 SENSE.md 的规则执行，不是一套固定脚本。M0–M1 期间没有独立进程：宿主就是 Claude Code（或 Codex），引擎以 subagent 的方式跑，产物落在 `m0/cards.json`。CLI 之后把这套步骤固化，规则不变。
- 证据来源的优先级：用户在会话里自己写的话（Claude Code / Codex 日志的用户轮次） ＞ 指令文件（CLAUDE.md / AGENTS.md） ＞ 浏览器记录。浏览器记录单独不能成判断：它只记标题和点击，没有理由；它能提供对照和问题，权重最低。
- M0 第一版（Chrome 记录）作废为参考；M0 第二版从会话日志生成。

## 原因
- 用户 2026-10-20 的原话："要看我的 log 而不是看我的 tab"；"请用 agent 执行，当然，早期我们可以用 claude 的界面执行"。
- 第一版判断卡的理由是从浏览器标题推出来的，用户反馈"莫名其妙"。判断的四要素里理由和对照必须是用户说过的话，日志里有，标题里没有。

## 影响
SENSE.md 5.2、7.1、7.5、13 调整；`m0/` 重做；决策 0007、0013 中"适配器 / 脚本"的表述按本条理解。
