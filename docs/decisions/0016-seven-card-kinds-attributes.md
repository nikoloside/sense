# 0016 · 卡按"是什么"分七种；卡背后是属性；一张卡有类别、动作、品级三个轴

日期：2026-10-21 · 状态：已定 · 替代 0015（已撤回）；修订 0012 中"判断卡是档案的唯一卡面"的落点

## 决策
- 卡是用户生活里的一个东西，按它是什么分七种：判断（一次决定）、推荐（之前推荐过并被喜欢的）、人物（联系过、高评价、关注、cold mail 过的人）、关注（长期追踪的内容）、兴趣、金句、收藏（截图与书签合并，角标区分）。
- 一张卡同时有三个互不替代的轴：类别（是什么）、动作（对它做什么，由类别决定）、品级（颜色，见 0017）。
- 属性是卡背后的 sense，即数据模型里的 Judgment（场 / 选择 / 对照 / 理由）。每张卡挂 1–3 条；同一条属性串起很多卡。用户每次留下、打开、跟进一张挂着某属性的卡，这条属性就算被用了一次。

## 原因
- 作者 2026-10-21 否决"两种卡"："不要这个判断"；要求按"卡是什么"分。随后明确："这两个是行为（动作）、是什么（卡的 category）和状态（卡的颜色）"。
- 判断卡的意思也被作者重新定义：是"我们在什么时候做什么决定的卡"，而不是一条抽象的品味判断。抽象判断因此降为属性。
