# 0034 · 通话里的 agent 能替你记卡、能上网查；通话状态看得见

日期：2026-10-25 · 状态：已定 · 补充 0030（语音通话）

## 作者说的
> 现在聊天过程中，它还没有办法去连这个我们的 Agent……让这个 Agent 帮我们做事情，就可以帮我们记录卡片。比如说可能我喜欢的一些东西，我可以全跟它说。

> 外面的网页搜索也加上吧

> 怎么感觉现在断掉一次之后，再打开连接，它就不回应我了？……我现在看不到他是否在思考，或者是是否在聊天，或者是可能是否已经断掉了。

选项里选了：品级看你怎么说；直接记、挂断后可撤销；挂断后自动上网核对。

## 记卡
- 大脑在回话末尾写不念出来的标记，页面收到就执行，嘴上只说一句「记下了」，不停下来确认：
  - 〔卡 种类|名字|他的原话一句|强/弱〕：新卡。明确说喜欢、在意 = 强 → 铜卡；顺口提到、不确定 = 弱 → 石卡。口袋里已有同名的卡就改成「碰」。
  - 〔碰 编号|原话〕：已有的卡记一次碰，原话加进证据；石卡被说喜欢就成铜卡。
  - 〔跟 编号或名字〕：开始跟（银卡）。
- 只记他亲口说的；从 A 推 B 只能用嘴问（跨领域规则不变）。别人说的不记。
- 证据只存他说的那一句；通话全文照旧不存。
- **挂断后**：弹出「这通电话记了 n 张」，新记的和开始跟的都能撤销。新记的卡先标「听来的」，后台 agent 上网核对名字（语音会听错同音字）、补一句介绍、链接和最多两条已有属性；核对不出来就保留「听来的」。

## 上网查
- 通话大脑能用 WebSearch、WebFetch（只有这两样，不读写本机、不跑命令）。查之前先说半句「我查一下」；一轮最多查两次；查到了用嘴说出自哪个网站。
- 链接和网址从不念出来：页面在送去合成声音之前把它们滤掉。

## 状态看得见、断了能自己恢复
- 桌宠脚下一个状态条：启动语音服务 / 开麦克风 / 连接中 / 在听 / 你在说 / 在想 / 在查网页 / 在读网页 / 在说。快捷菜单的通话按钮同样显示。
- 断了桌宠说为什么断（你挂断、语音服务那边断了、麦克风没打开、连不上……）。
- 语音服务端口开着但不回应（/healthz 两秒内不答 200）：Sense 把自己起的那个重起。拨号 8 秒没收到 hello：重起服务、自动重拨一次；还不行才放弃并说明。
- 每一步都记进 engine.log（只记步骤和原因，不记说的话）。
