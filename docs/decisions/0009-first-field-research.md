# 0009 · 第一个 field 是作者的研究领域，输出"该认识谁 / 该读什么 / 该看哪些项目"

日期：2026-10-20 · 状态：已定

## 决策
第一个 field 用作者本人的论文、仓库和相关会话做 context，KB 从 arXiv / Semantic Scholar / OpenAlex / GitHub / HN 扩展。体验对标"找我的论文 → 推荐该认识谁"。第二个 field 用游戏（Steam 等来源）验证同一引擎可以换领域。

## 原因
- 本地 context 最密集的就是研究和开发，判断最容易提炼和验证。
- "该认识谁"是最能体现 sense 独特性和价值的推荐，光靠平台算法得不到。
- 作者本人就是第一个用户，能立刻判断推荐对不对。
