Sense 系统框架

一张卡从进口袋到变成你的口味，中间经过哪些机制；后台的 agent 怎么被调起来；界面用哪套设计语言。图里的数字都是现在 app 里真实在用的值。

1总循环

五层从左往右流，你的每个动作再流回左边。左边的入口只负责"放进来"，右边的产出只负责"给你看、给你东西"，中间的档位和追踪台决定一张卡值不值得 agent 花力气。

2一张卡的一生

档位表示 agent 愿意为它花多少力气，跟卡是不是"好"无关。只有金卡会往外找新东西，其他档位都只看卡自己。

石卡

刚进口袋：截图、扫出来的履历、整理出来的作品。

一次都没处理过的，7 天后碎掉（截图 30 天），快碎时卡面出裂纹。碎卡进仓库，只留标题和来源，能捡回来。

铜卡

你有点在意：留下过、打开过；或者跨很多周反复看过（品味整理里的「常驻」）。

→ 银：你点「跟」，或碰满门槛（现在 3 次，2–8 之间自己调）。60 天没碰归档。

银卡

自动坐上追踪台，只盯它自己：作品查新一话、新作；人查新动向；判断和金句去日志里找新例子和反例。

→ 金：两张以上银卡说得出同一个已确认的为什么，才能融合。

金卡

一种口味。每周按这个口味往外找 2–3 样你还没有的，生成新的铜卡。

拆开（unfuse）就退回原来那几张银卡。

门槛自己调

  • 自动升上银的卡被你取消跟：门槛 +1
  • 你主动跟一张还没碰够的铜卡：门槛 −1
  • 每次调整都记下原因，引擎面板里看得到

NEW 和碎卡

从没打开、留下、跟过、放上追踪台的卡挂 NEW。石卡一直是 NEW 就会碎；抽卡时被另一张比下去会少 3 天（早碎），你也可以在卡上点「碾碎」立刻碎掉。碎卡记得"查到过"，以后整理和推荐会跳过它，也告诉 agent 你没理会，但不当成你讨厌。

跨领域只提问

"喜欢的番和听的歌是不是一个路子"这种联系，只能写成要问你的是非题。你答了「是」才算数，不会自己当成结论。

任务不碰档位

设置里的任务、XP、等级只是让你把口袋用起来。它们读操作记录，但不会改任何一张卡的档位。

3引擎

桌面版不自带模型。每次要 agent 干活，就在本机起一个 Claude Code，用你登录的账号和它的默认模型。prompt 从标准输入进去，只收 JSON；工具按任务给，不给就是一个都没有。

节拍

  • 追踪台：每 30 秒看一次有没有到点的座位，一次只跑一个
  • 新上座的银、金卡错开 2 小时排队
  • 座位节奏：每天 / 每周 / 每月
  • 归档检查：每小时
  • 品味整理：每周，每小时检查一次

开关

设置 → 引擎 → 暂停：追踪台和每周整理都停，手动按钮照常能用。app 关着的时候不跑，下次打开先补到点的。

网页版

网页版不联网，也不会自己转。它用 artifact 的 sample 能力问 Claude，结果标「未核实」。

4设计语言

像一个口袋里的卡牌游戏：像素字做标题和数字，正文用好读的黑体；卡的边框颜色就是档位，色点就是种类。界面上的颜色都来自同一组主题变量，换配色时卡、背景、展示卡一起变。

主题变量（每套配色都要给全）

  • --felt / --felt-2 / --felt-line 底色、面板、分隔线
  • --chalk / --chalk-2 底色上的字
  • --paper / --ink / --ink-2 卡面和卡上的字
  • --accent / --accent-2 / --on-accent 按钮、选中、进度
  • --deep* 深一层的盒子（委托、转盘）
  • --bg-a … --bg-e 背景像素漩涡的五级色

字

DotGothic16 像素字

标题、标签、等级、数字。只用在短字上。

Noto Sans SC 正文

卡面、说明、证据。正文 13–15px，行高 1.6。

卡

纸色卡面，3px 档位色边框，顶部是按卡 id 生成的像素图，左上角种类色点。点开是详情抽屉。

领域面板

Sense 页的基本单元：一个领域一块，按瀑布流排。一行一张卡：档位色块、标题、证据。

任务便签

任务板是软木板纹理，每个任务是钉着的纸条，轻微歪斜。完成了才出「领取」。

角色

12×14 像素小人，帽子跟着口袋里卡最多的领域换，衣服是主题色。属性只写计数（几张卡、跑过几次），不给品味打分。

布局

宽屏两栏：左边固定展示卡和要问你的，右边内容。980px 以下合成一栏，侧边留 16px。

动效

卡飞进口袋、升档时闪一下、背景像素慢慢转。系统设了减少动态时背景只画一帧。

5数据边界

会读

  • 你自己的 Chrome profile 的履历和书签（别人的 profile 不读）
  • Claude Code / Codex 会话里你自己打的字
  • 你导入的 Takeout / Spotify 文件
  • 你截的图、你打开剪贴板后复制的文字

不读

  • 登录、支付、银行、医疗、签证、地址、邮件、日历、后台页面
  • 密码管理器、聊天、邮件 app 里复制的东西
  • 像密钥、邮箱、长串数字的文字

怎么存

  • 状态只有一个文件：~/Library/Application Support/Sense/pocket-state.json
  • 原始记录读完就删，卡里只留标题、次数、日期，不留链接（书签除外）
  • 不上传；只有调 agent 时把整理好的摘要交给本机的 Claude Code
